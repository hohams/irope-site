# Рабочие сайты

Единый шаблон для iRope, iSpec и Mobile Kids. Он построен на Astro: быстрый, простой и пригодный для статического размещения на Hostinger Business.

## Как попросить Codex внести изменения

Пишите обычными словами, например: «для iRope добавь услугу мойки фасадов», «замени телефон iSpec» или «подготовь литовскую версию главной страницы». Codex найдёт настройки сайта в `src/content/sites.ts` и нужные блоки в `src/components/`.

## Локальный запуск

1. Установите Node.js 20+.
2. Выполните `npm install`.
3. Скопируйте `.env.example` в `.env` и при необходимости задайте адрес сайта.
4. Выполните `npm run dev`.

## Публикация iRope на Hostinger

Проект статический: ему не нужны PHP, база данных или сервер Node.js после сборки. Для iRope используйте следующие параметры сборки:

```text
SITE_URL=https://irope.lt
PUBLIC_SITE_ID=irope
```

`astro.config.mjs` уже настроен на статическую сборку, `https://irope.lt` и генерацию sitemap. Если переменные не заданы, iRope и адрес `https://irope.lt` остаются значениями по умолчанию.

### Что сделать вручную в Hostinger

1. В hPanel откройте **Websites** и создайте или выберите пустой сайт для домена `irope.lt`. Не используйте Hostinger Website Builder: для готового Astro-сайта нужен файловый хостинг.
2. На компьютере в корне проекта выполните:

   ```bash
   npm ci
   npm run build
   ```

   Готовый сайт появится в папке `dist/`. Перед сборкой при необходимости задайте две переменные выше. `PUBLIC_CONTACT_FORM_ENDPOINT` задавайте только после выбора реального обработчика формы; это публичный URL, а не место для ключей или паролей.
3. В hPanel откройте **Websites → Dashboard → File Manager** для сайта `irope.lt`. Откройте папку именно этого домена — `public_html`.
4. Загрузите **содержимое** папки `dist/` прямо в `public_html`: в результате путь к главной странице должен быть `public_html/index.html`, а не `public_html/dist/index.html`. При замене уже работающего сайта сначала сохраните его резервную копию.
5. После того как файлы загружены, в настройках сайта откройте раздел **SSL**, дождитесь активного сертификата и включите **Force HTTPS** для `irope.lt`.
6. Когда будете готовы к публикации, укажите для домена DNS-записи или nameserver’ы, которые показывает Hostinger. После распространения DNS откройте `https://irope.lt`, `/teisine-informacija/`, `/robots.txt` и `/sitemap-index.xml` и проверьте главные ссылки и контакты.

Hostinger открывает файловый менеджер сайта в папке `public_html`; файлы нужно размещать в ней, а не уровнем выше. Подробности: [Hostinger — File Manager](https://support.hostinger.com/en/articles/4548688-basic-actions-in-the-file-manager). После установки сертификата HTTPS можно включить в разделе SSL: [Hostinger — Force HTTPS](https://support.hostinger.com/en/articles/1583201-how-to-enable-or-disable-https-for-your-website-at-hostinger).

DNS, SSL и загрузка файлов намеренно не выполняются из репозитория: это действия в аккаунте Hostinger и выполняются владельцем домена.

## Контактная форма

До подключения сервиса форма показывает понятный способ написать на почту. Когда будет выбран сервис обработки заявок, в настройках развёртывания указывается `PUBLIC_CONTACT_FORM_ENDPOINT`; адрес не должен содержать пароли или ключи.
