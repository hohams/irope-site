# iRope — исходники сайта

Работающий сайт: https://irope.lt. Статический Astro, 37 страниц.

## Сборка

Node.js 22, `npm ci`, затем `npm run build`. Результат в `dist/`.
По умолчанию SITE_URL=https://irope.lt и PUBLIC_SITE_ID=irope.
В GitHub оставлена одна проверка `.github/workflows/ci.yml`.

## Публикация и восстановление

Сайт размещён на VPS Hostinger hohams.cloud, а не в public_html общего хостинга.
Корень стека: `/srv/stacks/irope`. Compose-файл: `compose.yaml`.
Сервис `web` раздаёт статические файлы nginx из `releases/photo-<commit>`.
Публичный HTTPS обслуживает Caddy. Форма отправляет POST на `/api/contact`;
её обработчик и секреты находятся на VPS и не входят в публичный GitHub.

Для обновления собрать точный коммит в отдельной папке, проверить 37 HTML-страниц,
скопировать dist в новый release, изменить только bind mount сервиса web,
проверить `docker compose config -q`, выполнить `docker compose up -d --no-deps web`.
Проверить публичные страницы и файлы. При ошибке вернуть прежний mount и пересоздать web.
Не заменять весь compose-файл и не останавливать остальные сервисы.

## Резервные копии

`main` — рабочая версия; `backup/pre-publication` — единственная резервная ветка.
При обновлении резервной копии ветка перемещается вперёд до проверенной версии;
история прежних коммитов сохраняется. Название ветки историческое.

Для восстановления всей серверной системы использовать снимок VPS в Hostinger:
VPS → hohams.cloud → Snapshots & Backups. Он включает серверные файлы,
конфигурацию и обработчик формы; GitHub хранит исходники и изображения.
Восстановление снимка затрагивает весь VPS, включая другие приложения,
поэтому его нельзя выполнять для обычного отката одной страницы.
Снимки имеют срок хранения, указанный Hostinger; это не бессрочный архив.
Внешняя почта и DNS управляются отдельно и не восстанавливаются из диска VPS.
Не публиковать секреты, ключи и серверные .env в GitHub.

## Фотографии

Веб-копии ограничены длинной стороной 1800 px; JPEG quality 82.
Сравнение дымоходов опубликовано как WebP. Логотип ограничен 512 px.
Оригиналы оптимизированных файлов от 2026-11-09 сохранены вне репозитория
в соседней папке `irope-originals-2026-11-09` и в истории Git до оптимизации.
